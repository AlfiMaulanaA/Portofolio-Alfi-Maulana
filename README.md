## 🚀 About This Repository

The application is built using modern web technologies:
- **Framework:** Next.js (App Router / Pages)
- **Library:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & React Icons

## 🏃‍♂️ Getting Started (Local Development)

If you'd like to run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AlfiMaulanaA/Portofolio-Alfi-Maulana.git
   cd Portofolio-Alfi-Maulana
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)
