## Stack Teknis Aplikasi

Stack utama berdasarkan `package.json` dan source aplikasi:

- **Framework:** Next.js 14 App Router
- **Runtime UI:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Theme:** next-themes, default theme `dark`
- **UI primitives:** Radix UI, shadcn-style components pada `components/ui`
- **Icons:** lucide-react dan react-icons
- **Font:** Poppins dari `next/font/google`

Layout root menggunakan `ThemeProvider` dengan `defaultTheme="dark"` dan `enableSystem={false}`. Komponen `ClientLayout` dimuat secara dynamic dengan SSR disabled karena halaman banyak memakai hooks dan animasi sisi client.
